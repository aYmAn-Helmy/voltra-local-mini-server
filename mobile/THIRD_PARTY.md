# ModernSmartHomeUI — design inspiration

The mobile Voltra v1.5.0 animated device cards and interactions are custom
Flutter components designed for Voltra's API, with visual inspiration from
the open-source **ModernSmartHomeUI** project.

Source: https://github.com/mitchkoko/ModernSmartHomeUI

Original author: Mitch Koko (2024).

The project is distributed under the MIT License. Its notice is reproduced
below for attribution. Voltra does not ship ModernSmartHomeUI's placeholder
smart-device state, screens, fonts, or icon binaries; its own controls issue
verified local-server commands and display real relay state.
